MindfulDay — Architecture Overview

A personal, single-user mindfulness & task-tracker PWA. Its purpose: a mindful pause at every task transition. One user, two installed devices — iPhone and Windows desktop. Vanilla HTML/JS/CSS, no framework, no build step.

The system

Everything meets at one JSON blob

Static files are served by Firebase Hosting; all app state lives as a single JSON blob at /state in the Realtime Database. Google sign-in gates every read and write to one email address. Two Cloud Functions handle push; the Isha calendar comes from a public Google Calendar. Each device keeps a full copy of state in localStorage as its offline vault.

Sync — hard-won, do not regress

Newest copy wins, in both directions

iOS and Windows freeze background PWAs; the SDK’s unsent writes die with the process, so localStorage is the offline vault and every saved state carries lastUpdate (ms) + lastUpdatedBy (device id). All reconciliation goes through refreshStateFromServer(tag) — never a raw once() adopt.

Awareness

Overdue is ambient only

No popups — explicitly rejected as “a dialog asking a question the app can’t act on”. The running tile and the green pill simply change colour, gated on deepLinkReady.firebase so stale pre-sync state never flashes red. Popups are reserved for push notifications.

Notifications

Web Push with VAPID — deliberately not FCM

The public key lives in app.js; the private key only in Secret Manager (VAPID_PRIVATE_KEY — the repo is public). Subscriptions are stored per device at /pushSubs/<deviceId>. This is his one “special” notification — the phone is otherwise on silent with all reminders off.

Features

What the app does, and why it does it that way

  • Activities — 20 tiles defined in settings_activities.json (id, label, icon, target minutes). Switching goes through a slide-to-confirm modal into confirmStart(activity, atTime, opts); atTime backdates, opts.quiet suppresses the quote. Wake Up rotates the day (history → yesterday).
  • Quotes — 135 deduped Sadhguru quotes; a device-local shuffle bag (quoteBagV2 in localStorage) that must never re-enter synced state — syncing it once caused repeats. The Wake Up card also shows today’s Isha calendar entries.
  • Isha calendar — public calendar via Calendar API v3, keyed by the Firebase web API key (origin-restricted, so local testing needs a Referer header). Cached per day; degrades silently.
  • Sadhana player — SADHANA_MODES config (audio:null = silent Shoonya); a persistent <audio> element, an intent flag with a 5-second watchdog that resumes at position, screen Wake Lock, Media Session, one round play/pause button. Adding a meditation is one config line + an icon in the SW asset list.
  • Siri / deep links — ?switch=<id-or-label> does a quiet switch after the settings + firebase readiness gates; Shortcuts open the URL (a browser flash is accepted).

Shipping

Deploy: three stamps that must move together

Because the update path is the service worker, version.json, the ClientVersion in app.js, and CACHE_NAME in sw.js must change on every deploy — update_version.js stamps all three; deploy.bat automates the whole sequence.

  1. Stamp — node update_version.js
  2. Deploy — npx -y firebase-tools deploy --only hosting --project mindfulday-gsb (functions and database rules deploy separately)
  3. Commit & push — git add -A && git commit && git push origin main
  4. Verify — curl -s https://mindfulday-gsb.web.app/version.json. Ignore stale “Authentication Error” lines mid-deploy; trust “Deploy complete” + this curl.

On the device: location.reload(true) is a no-op on iOS, so performUpdate clears all caches then plain-reloads. Settings shows Client vs Server version; an orange badge on the gear means the server is newer.

Terrain

iOS PWA quirks — measured, not theorised

Audio is never intercepted

iOS streams audio via HTTP Range requests; a cached full-body 200 kills playback mid-file (the “stops after 10 min” bug). The SW fetch handler bails on destination === 'audio' or /audio/ URLs.

Touch events lie

touchend has an empty e.touches — use changedTouches. Handle touchcancel, or the confirm slider sticks mid-way.

The dead zone is structural

Container is position:fixed; top:0; height:100%. In standalone mode the home indicator lives inside the dead zone, so a media query drops the safe-area padding there.

On-device debugging

A VP … viewport-geometry line goes to Settings → Debug Log — the tool for layout debugging on the actual phone.

Boundaries

Deliberate decisions and declined ideas

Declined

Unauthenticated command queue

Token-protected /commands/<token>/queue — client code still exists in app.js, but the unauth-write rule was refused. Never deploy it without fresh explicit consent.

Deferred

Native iOS app

No App Store, no $99/yr for now. If ever: a Capacitor wrap, never a rewrite. Free-Apple-ID sideloading rejected (no push entitlement, 7-day expiry, no Mac).

By design

Per-device state

Quote shuffle bag and countdown-bar settings stay in localStorage, unsynced — known and accepted.

Legacy

Old homes

gsbellu.github.io is legacy — don’t maintain it. The old Firebase project mindfulday-timer is inaccessible — never deploy there.
